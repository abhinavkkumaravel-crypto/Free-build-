* Basic web calculator — HTML, CSS, JavaScript

This simple app provides basic arithmetic (addition, subtraction, multiplication, division), decimal numbers, parentheses, clear and backspace, and keyboard input. It is added as a small static web page you can run locally.

How to use

1. Clone the repository (or fetch this branch):

   git fetch origin add-basic-calculator-app
   git checkout add-basic-calculator-app

2. Open index.html in your browser:

   - double-click index.html, or
   - serve it with a static server (e.g., `npx http-server` or `python -m http.server`).

Notes

- Evaluation uses a simple input filter to allow only numbers, spaces, parentheses, decimal points, and the operators + - * /. This is not a substitute for a full expression parser, but is sufficient for basic calculations.
- If you want me to add more features (history, keyboard layout, scientific functions), tell me which ones and I'll extend the app.
